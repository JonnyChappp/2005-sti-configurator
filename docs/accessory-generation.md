# Reconstructed accessory images

Several accessory-card images were generated with the built-in ImageGen tool where the original brochure supplied only a tiny illustration. They are visual aids, not historical evidence; provenance remains in the repository and the detail dialog's research-source section.

Files:

- `references/2005-sti/accessory-originals/mirror-homelink.png`
- `references/2005-sti/accessory-originals/floor-mats.png`
- `references/2005-sti/accessory-originals/wheel-locks.png`
- `references/2005-sti/accessory-originals/security-system.png`
- `references/2005-sti/accessory-originals/paint-aware/hood-protector-*.png`
- `references/2005-sti/accessory-originals/paint-aware/fog-lights-*.png`

Prompt set:

- HomeLink mirror: period-correct early-2000s auto-dimming interior mirror with compass display and three lower-bezel HomeLink buttons; OEM black housing; clean gray product-photography background; no logos, text or watermark.
- Floor mats: an edit of the preserved four-piece LHD product layout into Subaru's documented J5010SS700 specification—deep factory blue carpet and binding, two driver-retention grommets, and no embroidered logo—on a clean gray product-photography background. The official 2005 cabin image supplied the color reference.
- Wheel locks: four chrome locking lug nuts and one matching key adapter; period-correct compact OEM hardware; clean gray product-photography background; no logos, text or watermark.
- Security system: period Impreza control module, horn, relays, extension harness, mounting hardware and two window decals, arranged as a sharp OEM product photograph. The 2002–04 kit photograph supplies component geometry; the result does not claim a readable 2005 kit part label.
- Hood protector: factory smoke-tinted hood protector installed across the leading edge of the exact 2005 STI hood, with a matched front three-quarter composition in all five factory paint colors.
- Fog lights: matched pair of round projector lamps installed in the STI lower bumper with color-keyed surrounds, using the same composition in all five factory paint colors.

All original outputs are 1536 × 1024 PNGs. WebP delivery copies at quality 88 are used by the site. The superseded black floor-mat reconstruction is retained as `floor-mats-black-v1.png`; the active image follows the Subaru catalog's blue/no-logo description, but the rendered weave and fine edge construction remain illustrative. The security kit, mirror and wheel-lock geometry are visual reconstructions and must not be used to identify an original part. Full paint-variant prompts and files are recorded in `accessory-paint-generation.json`.
