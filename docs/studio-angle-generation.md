# Side and rear studio asset generation

The 20 side/rear variants were created with the built-in ImageGen tool. Original 1536 × 1024 PNGs are stored in `references/2005-sti/studio-originals/`; WebP delivery copies are stored in `public/assets/studio/`.

The side base uses the original blue/gold side reference and the rear base uses the original blue/gold rear reference. Both bases were reconstructed onto the same pale-gray studio backdrop, with the plate removed and aftermarket mudflaps omitted. Every remaining variant used its matching base with this prompt pattern:

> Use case: precise-object-edit. Asset type: mobile vehicle configurator. Edit target: supplied 2005 US Subaru WRX STi studio illustration. Change only body paint to [documented paint] and BBS wheel finish to [gold/silver]. Preserve exact camera angle, composition, 2005 body geometry, original bumpers, hood scoop, large rear wing, stock ride height, black trim, gold Brembo calipers, tires, glass, lighting and pale gray background. All painted panels, mirrors, skirts and wing must match. Keep the entire car in frame at 1536 × 1024. No added accessories, roof spoiler, text or watermark.

For rear views, the prompt additionally locks the taillights and stock single exhaust exit. These are AI-assisted product illustrations rather than historical evidence or calibrated paint samples. Fine badges, reflections and wheel details can vary. The images do not depict accessory selections.
