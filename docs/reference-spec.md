## Refinement pass

Mobile Colors uses the reference's floating Change View label, blue dropdown end-cap, 50 px top spacing, pale studio stage, full-width swatch band and larger step labels. The heading remains available to assistive technology but is visually hidden on this step at mobile widths. Active navigation steps scroll into view. All ten paint/wheel combinations provide matching front, side and rear compositions.

Interior mode provides the same three-choice camera control as exterior mode: Cockpit, Cabin and Rear. Each 1536 × 1024 image is an official-brochure-based reconstruction of the U.S. left-hand-drive blue/black Ecsaine cabin. The rear view has five paint-aware variants so its exposed door jamb always matches the selected exterior color.
